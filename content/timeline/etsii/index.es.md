# Descripción del Grado

Completé un programa integral de Informática con enfoque en ingeniería de software, algoritmos y sistemas distribuidos.

## Cursos Clave

- Algoritmos Avanzados y Estructuras de Datos
- Sistemas Distribuidos
- Arquitectura de Software y Patrones de Diseño
- Sistemas de Bases de Datos
- Sistemas Operativos

## Logros Académicos

- Graduado con honores (GPA: 3.8/4.0)
- Lista del Decano por 6 semestres
- Completé tesis de grado sobre algoritmos de consenso distribuido

## Proyectos

- Desarrollé un almacén de clave-valor distribuido usando consenso Raft
- Construí un compilador para un lenguaje de programación personalizado
- Creé un servidor web multi-hilo desde cero
